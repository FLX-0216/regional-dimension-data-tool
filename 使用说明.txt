        区域维度数据处理与导出 工具 · 使用说明
══════════════════════════════════════════════════════════════

【一句话用法】
  把这个文件夹放在大家都能同步的共享盘（OneDrive / 企业微信微盘
  / 钉钉钉盘）里，每个人同步到本地后，双击「启动.bat」，
  浏览器自动打开就能用。


【第一次使用前的准备：安装 Python】
  本工具是 Python 程序，每个人自己的电脑需要先装一次 Python：
    1. 打开 https://www.python.org/downloads/ 下载最新版（3.10+）。
    2. 安装时务必勾选 “Add Python to PATH”（添加到环境变量），
       然后点 Install Now。
    3. 装完即可，无需其他配置。


【日常使用步骤】
  1. 确保本文件夹已同步到你的电脑（在共享盘里能看到）。
  2. 双击「启动.bat」。
  3. 等待几秒，浏览器自动打开 http://localhost:8501 即为成功。
  4. 用完后，关闭那个标题为 “Streamlit服务” 的黑色窗口即可退出。
     （直接关浏览器不会退出服务，要关黑窗口。）


【更新数据 / 程序】
  - 更新数据：把新的 parquet 放进 data_buckets 文件夹（或页面内上传），
    重新双击「启动.bat」即可生效。
  - 更新程序：把新的 app.py 等文件覆盖进本文件夹，重新启动即可。


【常见问题】
  Q1. 双击后提示“未检测到 Python”
      → 没装 Python，或装的时候没勾 “Add Python to PATH”。
        重装 Python 并勾选该选项即可。
  Q2. 浏览器打不开 / 显示无法访问
      → 等久一点（首次装依赖较慢）；或手动打开 http://localhost:8501。
  Q3. 提示 8501 端口被占用
      → 可能上次没关干净。关掉 “Streamlit服务” 黑窗口再试；
        若仍不行，重启电脑后重试。
  Q4. 依赖安装很慢或失败
      → 确认网络正常；失败时右键「启动.bat」选“以管理员身份运行”重试。


【说明】
  - 每个人都是在本机独立运行，互不影响，也不需要同一局域网。
  - 共享盘只用来统一分发代码和数据，真正的运行在各人电脑上。
  - 数据文件（data_buckets/*.parquet、mapping_table.parquet）必须
    保留在本文件夹内，否则页面打开后数据池为空。
